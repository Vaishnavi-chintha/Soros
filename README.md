# Soros - One stop project stack initializor

## Introduction
Soros is a web application that provides a user-friendly interface for initializing project stacks. It allows users to select from a variety of pre-configured stacks, including popular frameworks and tools, and generates the necessary files and configurations to get their projects up and running quickly.

## Features
- **Pre-configured Stacks**: Soros offers a selection of pre-configured stacks, including options for frontend, backend, and full-stack development.
- **Customizable Configurations**: Users can customize their stack configurations to suit their specific project needs.
- **File Generation**: Soros generates all the necessary files and configurations based on the selected stack, saving users time and effort
- **Cost-analyzer**: Soros includes a cost-analyzer feature that estimates the costs associated with using different stacks, helping users make informed decisions about their project setup.
- **User-friendly Interface**: The application provides an intuitive and easy-to-navigate interface, making it accessible to developers of all skill levels.

## Installation
To install Soros, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/soros/soros.git
   ```
2. Navigate to the project directory:
   ```bash
   cd soros
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```
